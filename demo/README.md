# UI演示页面说明

## 📁 文件列表

- **index.html** - 首页演示
- **tool-detail.html** - 工具详情页演示
- **content-detail.html** - 内容详情页演示（AI快讯/教程/百科）

## 🎨 设计特点

### 配色方案
- **主色调**：靛蓝色 `#4F46E5`（蓝紫色系，商务科技感）
- **背景色**：浅灰 `#F9FAFB`
- **卡片背景**：纯白 `#FFFFFF`
- **文字色**：深灰黑 `#111827`、中灰 `#6B7280`

### 布局特点（紧凑设计）
- **左侧固定分类导航**（240px宽）
- **紧凑的内容布局**，减少不必要的留白
- **简洁的搜索框**，无大图/域名展示
- **5列工具卡片网格**（Logo和名称同行，更紧凑）
- **内容轮播区**：5列网格，超过1行时上下滚动（最大高度190px）
- **广告位智能显示**：无广告时自动隐藏，不占用空间
- **推荐专区行数可配置**：后台可设置显示1-N行
- **响应式设计**：适配桌面、平板、移动端

### 交互效果
✅ 卡片悬停放大/阴影效果  
✅ 页面淡入动画  
✅ 滚动加载动画（简化版）  
✅ 评分星星交互  
✅ 搜索框焦点效果  
✅ 内容轮播区悬停遮罩效果  
✅ 标签切换动画  

## 🖥️ 如何查看

### 方法1：直接在浏览器中打开
1. 双击任意HTML文件
2. 会在默认浏览器中打开

### 方法2：使用本地服务器（推荐）
为了获得更好的体验，建议使用本地服务器：

```bash
# 如果你安装了 Python 3
cd demo
python -m http.server 8000

# 如果你安装了 Node.js 的 http-server
npx http-server -p 8000

# 如果你使用 VS Code
# 安装 "Live Server" 扩展，右键HTML文件选择 "Open with Live Server"
```

然后访问：
- 首页：http://localhost:8000/index.html
- 工具详情页：http://localhost:8000/tool-detail.html
- 内容详情页：http://localhost:8000/content-detail.html

## 📱 响应式测试

### 桌面端（≥1200px）
- 完整布局，4列工具卡片网格
- 左侧导航固定显示

### 平板端（768px-1199px）
- 3列工具卡片网格
- 左侧导航可折叠或保留

### 移动端（<768px）
- 单列布局
- 左侧导航变为抽屉式（演示中隐藏）
- 搜索框全宽
