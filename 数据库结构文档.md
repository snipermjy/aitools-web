## 表结构设计

### 1. tools（AI工具主表）

存储所有AI工具的核心信息。

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | uuid | 主键 | PRIMARY KEY, DEFAULT uuid_generate_v4() |
| domain | varchar(255) | 工具域名（唯一标识） | UNIQUE, NOT NULL |
| name_zh | varchar(255) | 工具名称（中文） | NOT NULL |
| name_en | varchar(255) | 工具名称（英文） | NULL |
| slug | varchar(255) | URL友好标识（用于SEO） | UNIQUE, NOT NULL |
| summary_zh | text | 简介（中文，50-100字） | NULL |
| summary_en | text | 简介（英文） | NULL |
| description_zh | text | 详细介绍（中文，200-500字） | NULL |
| description_en | text | 详细介绍（英文） | NULL |
| features | jsonb | 主要功能列表（3-5个） | NULL, DEFAULT '[]' |
| use_cases | text | 适用场景 | NULL |
| logo_url | text | Logo图片URL（存储在R2） | NULL |
| screenshot_url | text | 网站截图URL（存储在R2） | NULL |
| official_url | text | 官网链接 | NOT NULL |
| pricing_type | varchar(20) | 价格类型 | NOT NULL, CHECK (pricing_type IN ('free', 'paid', 'freemium')) |
| pricing_info | text | 价格详细信息 | NULL |
| require_login | boolean | 是否需要登录 | DEFAULT false |
| require_api | boolean | 是否需要API | DEFAULT false |
| category_id | uuid | 分类ID（外键） | FOREIGN KEY REFERENCES categories(id) |
| tags | uuid[] | 标签ID数组 | DEFAULT '{}' |
| rating_avg | decimal(2,1) | 平均评分（1-5） | DEFAULT 0, CHECK (rating_avg >= 0 AND rating_avg <= 5) |
| rating_count | integer | 评分人数 | DEFAULT 0 |
| status | varchar(20) | 状态 | DEFAULT 'draft', CHECK (status IN ('draft', 'published', 'archived')) |
| audit_status | varchar(20) | 审核状态 | DEFAULT 'pending', CHECK (audit_status IN ('pending', 'approved', 'rejected')) |
| source | varchar(50) | 来源（crawler/manual） | DEFAULT 'manual' |
| crawler_site | varchar(255) | 爬取来源站点 | NULL |
| view_count | integer | 浏览次数 | DEFAULT 0 |
| seo_title | varchar(255) | SEO标题 | NULL |
| seo_description | text | SEO描述 | NULL |
| seo_keywords | text | SEO关键词 | NULL |
| created_at | timestamptz | 创建时间 | DEFAULT now() |
| updated_at | timestamptz | 更新时间 | DEFAULT now() |

**索引**：
```sql
CREATE INDEX idx_tools_domain ON tools(domain);
CREATE INDEX idx_tools_slug ON tools(slug);
CREATE INDEX idx_tools_category_id ON tools(category_id);
CREATE INDEX idx_tools_status ON tools(status);
CREATE INDEX idx_tools_created_at ON tools(created_at DESC);
CREATE INDEX idx_tools_rating_avg ON tools(rating_avg DESC);
CREATE INDEX idx_tools_tags ON tools USING GIN(tags);
```

### 4. ratings（评分表）

存储用户评分记录，每个IP对每个工具只能评一次。

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | uuid | 主键 | PRIMARY KEY, DEFAULT uuid_generate_v4() |
| tool_id | uuid | 工具ID | FOREIGN KEY REFERENCES tools(id) ON DELETE CASCADE, NOT NULL |
| ip_address | varchar(45) | 用户IP地址（支持IPv6） | NOT NULL |
| rating | integer | 评分（1-5星） | NOT NULL, CHECK (rating >= 1 AND rating <= 5) |
| created_at | timestamptz | 创建时间 | DEFAULT now() |
| updated_at | timestamptz | 更新时间 | DEFAULT now() |

**唯一约束**：
```sql
ALTER TABLE ratings ADD CONSTRAINT unique_tool_ip UNIQUE (tool_id, ip_address);
```

**索引**：
```sql
CREATE INDEX idx_ratings_tool_id ON ratings(tool_id);
CREATE INDEX idx_ratings_ip_address ON ratings(ip_address);
```

## 触发器和函数

### 1. 自动更新 updated_at 字段

```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = now();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 为所有表添加触发器
CREATE TRIGGER update_tools_updated_at BEFORE UPDATE ON tools
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_categories_updated_at BEFORE UPDATE ON categories
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

-- ... 其他表类似
```

### 2. 自动更新工具评分统计

```sql
CREATE OR REPLACE FUNCTION update_tool_rating_stats()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'DELETE' THEN
        UPDATE tools SET
            rating_avg = COALESCE((SELECT AVG(rating) FROM ratings WHERE tool_id = OLD.tool_id), 0),
            rating_count = (SELECT COUNT(*) FROM ratings WHERE tool_id = OLD.tool_id)
        WHERE id = OLD.tool_id;
        RETURN OLD;
    ELSE
        UPDATE tools SET
            rating_avg = COALESCE((SELECT AVG(rating) FROM ratings WHERE tool_id = NEW.tool_id), 0),
            rating_count = (SELECT COUNT(*) FROM ratings WHERE tool_id = NEW.tool_id)
        WHERE id = NEW.tool_id;
        RETURN NEW;
    END IF;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER update_tool_rating_after_insert AFTER INSERT ON ratings
    FOR EACH ROW EXECUTE FUNCTION update_tool_rating_stats();

CREATE TRIGGER update_tool_rating_after_update AFTER UPDATE ON ratings
    FOR EACH ROW EXECUTE FUNCTION update_tool_rating_stats();

CREATE TRIGGER update_tool_rating_after_delete AFTER DELETE ON ratings
    FOR EACH ROW EXECUTE FUNCTION update_tool_rating_stats();
```

### 3. 自动更新标签使用计数

```sql
CREATE OR REPLACE FUNCTION update_tag_usage_count()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'DELETE' THEN
        UPDATE tags SET usage_count = (
            SELECT COUNT(*) FROM tools WHERE OLD.tag_id = ANY(tags)
        ) WHERE id = OLD.tag_id;
        RETURN OLD;
    ELSE
        UPDATE tags SET usage_count = (
            SELECT COUNT(*) FROM tools WHERE NEW.tag_id = ANY(tags)
        ) WHERE id = NEW.tag_id;
        RETURN NEW;
    END IF;
END;
$$ LANGUAGE plpgsql;
```

## Row Level Security (RLS) 策略

Supabase支持行级安全策略，建议配置：

### 公开读取策略（前端）
```sql
-- 允许所有人读取已发布的工具
ALTER TABLE tools ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public tools are viewable by everyone"
    ON tools FOR SELECT
    USING (status = 'published');

-- 允许所有人读取分类和标签
CREATE POLICY "Categories are viewable by everyone"
    ON categories FOR SELECT
    USING (true);

CREATE POLICY "Tags are viewable by everyone"
    ON tags FOR SELECT
    USING (true);

-- 允许所有人读取已批准的评论
CREATE POLICY "Approved comments are viewable by everyone"
    ON comments FOR SELECT
    USING (status = 'approved');
```

### 后台管理策略
后台管理使用 Supabase Service Key，可绕过 RLS。
