# 爬虫功能使用指南

## 📌 功能说明

爬虫功能可以自动从其他AI导航站或单个URL获取工具信息，使用AI分析提取结构化数据，自动截图并保存到数据库。

---

## 🚀 快速开始

### 1. 配置环境变量

在 `admin/.env.local` 中配置以下环境变量：

```env
# Cloudflare R2（图片存储）
R2_ACCOUNT_ID=your_r2_account_id
R2_ACCESS_KEY_ID=your_r2_access_key
R2_SECRET_ACCESS_KEY=your_r2_secret_key
R2_BUCKET_NAME=your_bucket_name
R2_PUBLIC_URL=https://your-bucket.r2.dev

# 硅基流动 DeepSeek API（AI分析）
DEEPSEEK_API_KEY=your_deepseek_api_key
DEEPSEEK_API_BASE_URL=https://api.siliconflow.cn/v1
```

### 2. 安装依赖

```bash
cd admin
npm install
```

新增的依赖包括：
- `puppeteer` - 浏览器自动化和截图
- `cheerio` - HTML 解析
- `axios` - HTTP 请求
- `@aws-sdk/client-s3` - R2 上传（兼容 S3 API）

## 📖 使用方式

### 方式 1：爬取单个工具

**步骤：**
1. 登录后台管理系统（http://localhost:3001）
2. 进入"爬虫管理"页面
3. 在"爬取单个工具"区域输入工具网站 URL
4. 点击"开始爬取"

**示例：**
```
https://chatgpt.com
https://midjourney.com
https://claude.ai
```

**过程：**
1. 访问目标网站
2. 提取网站内容（HTML、标题、描述）
3. 使用 DeepSeek AI 分析，提取：
   - 工具名称（中英文）
   - 简介和详细描述
   - 推荐分类和标签
   - 价格类型
   - 主要功能
4. 截取网站首屏截图
5. 上传截图到 R2
6. 获取网站 Logo
7. 保存到数据库（**草稿状态**）

**结果：**
- 成功：工具保存为草稿，可在"工具管理"中查看和编辑
- 失败：显示错误信息

---

### 方式 2：批量爬取（从导航站）

**步骤：**
1. 进入"爬虫管理"页面
2. 在"批量爬取"区域选择目标导航站
3. 点击"批量爬取"按钮
4. 确认后开始爬取（可能需要较长时间）

**目标站点配置：**
数据库中 `crawler_sites` 表已预设了 5 个目标站点：
- AI工具集
- AI导航
- AI工具箱
- GPT应用商店
- AI产品榜

**过程：**
1. 访问目标导航站
2. 提取所有工具链接（使用 CSS 选择器）
3. 对每个链接执行"单个工具爬取"流程
4. 记录成功和失败数量
5. 保存爬取日志

**延迟设置：**
- 每个工具之间延迟 2 秒，避免请求过快

---

### 方式 3：测试爬取（不保存）

**用途：**
测试爬虫是否能正确分析某个网站，查看 AI 返回的结果，但不保存到数据库。

**步骤：**
1. 在"测试爬取"区域输入URL
2. 点击"测试"
3. 查看返回的 JSON 结果

## 🔧 AI 分析说明

### DeepSeek AI 提取的信息

AI 会自动分析网站内容并提取：

| 字段 | 说明 | 示例 |
|------|------|------|
| `name_zh` | 中文名称 | ChatGPT |
| `name_en` | 英文名称 | ChatGPT |
| `summary_zh` | 简短描述（20-50字） | 强大的AI对话助手，可以回答问题、写作、编程 |
| `description_zh` | 详细描述（100-300字） | ... |
| `categories` | 推荐分类 | ["AI对话"] |
| `tags` | 相关标签 | ["聊天机器人", "文本生成"] |
| `pricing_type` | 价格类型 | free / freemium / paid |
| `pricing_details` | 价格详情 | 免费版有限制，Plus版$20/月 |
| `require_login` | 是否需要登录 | true / false |
| `features_zh` | 主要功能 | ["对话问答", "代码生成", ...] |

## 📸 截图说明

**截图配置：**
- 分辨率：1920x1080（PC 端）
- 格式：PNG
- 范围：首屏（不截取全页）
- 存储：Cloudflare R2

**Logo 获取：**
尝试从以下位置获取：
1. `<link rel="icon">`
2. `<link rel="shortcut icon">`
3. `<link rel="apple-touch-icon">`
4. `<meta property="og:image">`
5. 默认：`/favicon.ico`

## 💾 数据保存

### 保存位置
- **数据库表：** `tools`
- **状态：** `draft`（草稿）
- **来源：** `crawler`

### 为什么保存为草稿？

爬虫获取的数据可能不完全准确，需要人工审核：
1. 检查工具信息是否正确
2. 调整分类和标签
3. 修改描述文字
4. 确认价格信息
5. 审核通过后，改为"已发布"状态

## 📊 爬取日志

每次爬取都会记录到 `crawler_logs` 表：

| 字段 | 说明 |
|------|------|
| `crawler_site_id` | 来源站点（批量爬取时） |
| `status` | 成功/失败 |
| `tools_found` | 找到的工具数量 |
| `tools_added` | 成功添加的数量 |
| `error_message` | 错误信息（如果失败） |
| `created_at` | 爬取时间 |

**查看日志：**
在"爬虫管理"页面底部的"爬取记录"表格中查看。

## ⚠️ 注意事项

### 1. 配置检查

爬虫功能需要以下配置：
- ✅ **必须：** Supabase 数据库
- ✅ **推荐：** DeepSeek API（AI分析）
- ✅ **推荐：** R2 存储（截图和 Logo）

**没有 R2 配置：**
- 截图和 Logo 上传会失败
- 但工具信息仍会保存（只是没有图片）

**没有 DeepSeek API：**
- 会使用默认数据
- 需要手动补充工具信息

### 2. 爬取频率

**建议：**
- 单个工具：随时可爬
- 批量爬取：每天不超过 2-3 次
- 同一导航站：间隔至少 1 小时

**原因：**
- 避免被目标网站封禁
- 减少服务器压力
- 节省 API 调用次数

### 3. 法律和道德

- ✅ 遵守目标网站的 `robots.txt`
- ✅ 合理的请求频率
- ✅ 不爬取需要登录的内容
- ✅ 尊重版权和隐私
- ❌ 不要滥用爬虫功能

### 4. 性能考虑

**单个工具爬取耗时：**
- 网站访问：3-5 秒
- AI 分析：5-10 秒
- 截图：2-3 秒
- 上传：1-2 秒
- **总计：** 约 15-20 秒/个

**批量爬取：**
- 50 个工具约需 15-20 分钟
- 请耐心等待，不要关闭浏览器

### 5. 浏览器资源

Puppeteer 会下载 Chromium：
- Windows：约 ~300MB
- 首次启动较慢（10-20秒）
- 建议：内存至少 4GB

## 🐛 常见问题

### Q1: 爬取失败，提示"超时"

**原因：** 目标网站响应慢或网络问题

**解决：**
- 检查网络连接
- 尝试访问目标网站是否能打开
- 增加超时时间（需修改代码）

### Q2: AI 分析返回空数据

**原因：** DeepSeek API 配置错误或余额不足

**解决：**
- 检查 `DEEPSEEK_API_KEY` 是否正确
- 检查 API 余额
- 查看后台管理系统控制台日志

### Q3: 截图失败

**原因：** 浏览器启动失败或网站加载失败

**解决：**
- Windows：确保安装了 Chrome/Edge
- 检查防火墙设置
- 查看控制台错误信息

### Q4: R2 上传失败

**原因：** R2 配置错误

**解决：**
- 检查 `R2_ACCOUNT_ID` 等配置
- 验证 R2 Bucket 权限
- 测试 R2 连接

### Q5: 爬取的工具已存在

这是正常的！爬虫会检查 `domain`（域名），如果已存在则跳过。

## 🔄 工作流程建议

### 推荐流程：

1. **首次使用：**
   ```
   测试爬取 → 检查结果 → 单个爬取 → 验证数据 → 批量爬取
   ```

2. **日常使用：**
   ```
   批量爬取（每天1次）→ 审核草稿 → 编辑完善 → 发布
   ```

3. **手动添加：**
   ```
   单个爬取 → 审核 → 编辑 → 发布
   ```

### 审核草稿的步骤：

1. 进入"工具管理"
2. 筛选"草稿"状态
3. 逐个查看：
   - ✅ 检查名称是否正确
   - ✅ 检查描述是否合适
   - ✅ 检查分类和标签
   - ✅ 检查价格信息
   - ✅ 检查截图是否清晰
4. 编辑修改
5. 改为"已发布"状态
